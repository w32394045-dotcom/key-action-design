# 关键动作还原教练（key-action-design）

把明星员工的隐性经验，还原为**可观察、可衡量、可复制**的关键动作链——让普通人照做，也能撬动目标成果。

源自绩效改进专家王志刚的方法论：关键动作还原四步骤 + 三重过滤 + IPO 验核 + 5 条质检要求。

## 30 秒上手（任何聊天 AI 都能用）

1. 打开 [`PROMPT.md`](./PROMPT.md)，复制「分割线以下」全部内容
2. 粘贴到 Kimi / 豆包 / DeepSeek / 文心一言 / 通义千问 / 腾讯元宝 / ChatGPT / Claude 任意一个 AI 的对话框，发送
3. AI 反问"你要还原新的，还是诊断现有的？" = 教练上岗 ✅

然后照着说就行：

| 我想…… | 直接这样说 |
|---|---|
| 复制销冠做法 | "我们销冠和普通销售业绩差3倍，流程一样，帮我把销冠的做法还原成关键动作，岗位是销售，想改进成交率。" |
| 萃取明星员工 | "我们有几位明星管家物业费催缴转化率特别高，帮我还原他们的关键动作。" |
| 诊断现有 SOP | "这份 SOP 员工总做不到位：'及时跟进客户、做好服务'，帮我诊断问题出在哪。" |

## 两种用法

| 文件 | 适合谁 | 怎么用 |
|---|---|---|
| **PROMPT.md** ⭐ | 所有人（任意聊天 AI） | 复制粘贴到对话框，即用即走 |
| **SKILL.md** | Claude Code / Cursor / WorkBuddy 等 Agent 工具用户 | 安装到 skills 目录，长期驻留 |

### WorkBuddy 用户安装

对话框发送：
```
/skillsimport https://github.com/wangzhigang-0913/key-action-design
```
或在【技能管理】→【从 Git 仓库导入】粘贴本仓库地址。

### Claude Code / Cursor 用户

```bash
git clone --depth 1 https://github.com/wangzhigang-0913/key-action-design.git
cp -r key-action-design ~/.claude/skills/key-action-design   # SKILL.md 需在目录根部
```

## 这套方法管什么、不管什么

✅ **管**：销冠/明星店长/标杆员工的做法复制；同一流程效果悬殊的动作级诊断；SOP"写了他做不到"的修复

❌ **不管**：设计谁都没做过的全新方案（那是创新）；没有明星员工的全新业务；员工"不愿做"的激励问题
